# TableCraft Contactless QR Menu & Order Manager

Digital restaurant menu and real-time table order management system for modern dining establishments.

---

## 🚀 Tech Stack
`Next.js` `TypeScript` `Tailwind CSS` `PostgreSQL` `Prisma`

---

## ✨ Key Features
- **Dynamic**: QR code generation per table for instant digital menu access
- **Live**: restaurant menu editor with category management, pricing, and dietary tags
- **Real-time**: kitchen order dashboard with instant status updates
- **Multi-language**: menu support and currency formatting
- **Mobile-first**: customer ordering experience with zero app download required

---

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+) or Python (3.10+) depending on project requirements
- Git

### Installation
```bash
# Clone the repository
git clone https://github.com/aqsam-husnain/tablecraft-qr-menu.git

# Navigate into project directory
cd tablecraft-qr-menu

# Install dependencies
npm install  # or: pip install -r requirements.txt

# Run the development server
npm run dev  # or: python app.py
```
